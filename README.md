# nui-biyori-legal

「ぬい日和」アプリの法的情報（プライバシーポリシー・利用規約）を GitHub Pages で公開するためのリポジトリ。

## 公開 URL

- ランディング: https://shin-sibainu.github.io/nui-biyori-legal/
- プライバシーポリシー: https://shin-sibainu.github.io/nui-biyori-legal/privacy.html
- 利用規約: https://shin-sibainu.github.io/nui-biyori-legal/terms.html

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | プライバシーポリシー / 利用規約への入口 |
| `privacy.html` | プライバシーポリシー本文 |
| `terms.html` | 利用規約本文 |

## 更新方法

各 HTML ファイルを直接編集して `main` にプッシュすると GitHub Pages が自動でデプロイする。
