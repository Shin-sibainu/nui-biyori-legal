子どもの安全基準

ぬい日和 / Shin Code

ぬい日和は、ぬいぐるみが好きな方のための写真共有 SNS です。運営者である Shin Code は、児童の性的虐待と搾取（CSAE）を一切許容しません。このページでは、ぬい日和が子どもの安全を守るために定めている基準と、その運用についてご説明します。

禁止していること

次の行為は、ぬい日和の利用規約およびガイドラインで明確に禁止しています。発見した場合は例外なく削除し、アカウントを停止します。

  • 児童の性的虐待に関するコンテンツ（CSAM）の投稿、共有、リンクの掲載
  • 児童を性的に描写、示唆、または性的対象として扱うあらゆる表現（実写・イラスト・生成物を問いません）
  • 未成年者に対する性的な誘引（グルーミング）、性的な会話、接触の要求
  • 未成年者の性的搾取につながる勧誘、取引、あっせん
  • 未成年者の個人情報や所在が特定できる情報の収集、公開

ぬい日和はぬいぐるみの写真を共有する場であり、人物を主題とした投稿はもともと想定していません。

利用できる年齢

ぬい日和は 13 歳以上の方を対象としています。13 歳未満の方はご利用いただけません。13 歳未満の方によるアカウントであることが判明した場合は、そのアカウントとデータを削除します。

通報の方法

子どもの安全に関わる懸念は、アプリを離れることなく、次のいずれの方法でもご報告いただけます。

  • 投稿・コメント・アカウントの通報：対象の「…」メニューから「通報する」を選び、理由を選択して送信します
  • アプリ内フィードバック：マイページ > 設定 > ご意見・ご要望 から、運営に直接ご連絡いただけます

アプリをお持ちでない方や、緊急性の高い内容については、下記のメールアドレスへ直接ご連絡ください。

info@nuibiyori.com

通報を受けたあとの対応

子どもの安全に関わる通報は、他の通報よりも優先して確認します。

  1. 内容を確認し、必要があれば直ちにコンテンツを非公開にします
  2. 違反が認められた場合、コンテンツを削除し、保存している画像も消去します
  3. 投稿したアカウントを停止します。再登録による回避が確認された場合も、同様に停止します
  4. 法令にもとづき、関係当局への報告が必要な場合は報告します

通報された方の情報を、通報された相手に伝えることはありません。

法令の遵守と当局への報告

ぬい日和は、子どもの安全に関する適用法令を遵守します。児童の性的虐待に関するコンテンツを確認した場合は、各国・地域の法令に従い、関係当局への報告を行います。捜査機関からの適法な要請には協力します。
